How to run it

  1. Open this on your cheapest Android and on an iPhone.
  2. Tap Start auto game and leave it running for 2–3 minutes. Watch the avatars for stutter.
  3. Switch When to draw to Always animating for the worst case, and the model to Robot, about 5× heavier than a Boostie needs to be.
  4. Put the app in the background for a few seconds and come back: both avatars should still be there.
  5. Tap Copy results after each run and paste them into the chat.
